## Important semantics and limits
- This is an **additive Python snippet overlay**, not a full source replacement,
  unified diff, or fetched commit diff. Existing snapshot edges are preserved.
- Selecting a PR/commit supplies its ingested changed-file scope, not code text.
  With several selected files, the snippet targets the first; PR paths are ordered.
- Dynamic dispatch, ambiguous imports and external/builtin calls are not guessed.
- Historical cold branches are presentation evidence, not warm executions. Their
  original node/edge identities are kept; no fabricated warm-to-cold edges appear.
- A known local UI override proactively disables replay. An external local write
  exercises the backend's authoritative HTTP 409 fingerprint guard in live smoke.
- Policies remain labeled demo scenarios; git authors remain unverified identities.
  Zero model tokens remain a no-model-call sentinel, not measured token savings.
