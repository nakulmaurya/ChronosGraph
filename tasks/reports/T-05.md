- Initial full run: **51 passed / 2 failed**. Both failures were real code-graph
  sandbox audit timeouts caused by independent variable-length OPTIONAL MATCH
  branches multiplying rows before aggregation. The canonical query now aggregates
  import paths, then call paths, then policy/issue evidence. The three-hop horizon
  and output contract are preserved; both real multi-hop assertions subsequently pass.
- The original catalog assertion required exactly two tenants, incompatible with
  requested discovery. It now requires the two defaults as a subset; all **40
  original test cases remain**. Independent dynamic/404/incomplete-state cases were added.
- Main's historical source counts and T-01/T-02 timing tables are not overwritten.
  The article's traversal prefix is refreshed byte-for-byte for the query change;
  its historic measurements are still explicitly historical.
- No guaranteed maintainer coverage or unrestricted arbitrary-repository support.
  Existing graphs are refused; failed new ingestions delete only their own graph.
  Optional fictional policies leave two real non-policy alternatives for triage.
  Tiny/unsupported policy topologies retain HTTP 409 rather than inventing evidence.
