### Latest live UI measurement (not an SLA)

Cold: 29.357 ms / 5 actions.
Replay: 13.533 ms / 3 actions.
Backend-reported speedup: 2.169x. Model tokens: 0.
This is **40% fewer tool actions**, not token savings. Across exploratory smoke
runs, wall-clock factors varied and one run was slower than cold (0.663x).
The UI renders such factors honestly; it does not insert sleeps, multiply timings,
or claim a guaranteed speedup. The fresh backend acceptance suite passed its
approved measured >1x gate. Timing variance remains a demo limitation.
