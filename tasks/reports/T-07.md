## Limits / decisions
- A validated diff is parsed as reconstructed Python, but graph changes remain an
  additive overlay: old edges are preserved, not a full replacement graph. Inputs
  are bounded to 32,000 patch chars / 500 AST observations; reconstructed code to
  1,000,000 chars. Arbitrary multi-file repository patch application is out of scope.
- The three-hop static planner is candidate selection, not a safe-skipping proof.
  Dynamic imports, fixtures, plugins, non-Python dependencies and stale snapshots
  require the full-suite CI gate. The displayed percentage must not authorize skips.
- Full raw source is stored locally for precise diffs/sizes but excluded from generic
  visual graph payloads. Slice caps/truncation are explicit. Commit authors are
  provenance evidence, not verified maintainers. Captured byte lengths mean UTF-8
  payload bytes after Python-source decoding, not necessarily original disk encoding.
- Repository constraints are not silently promoted into bi-temporal override rules.
  Policies/triage remain deterministic, not autonomous diagnosis or verified repairs.
- Enrichment is an explicit local single-writer operation; it is not a production
  concurrent schema-migration/transaction protocol. Original T-06 processes remain
  running on their prior version; T-07 testing used separate loopback services.
- No product dependency, paid model, graph reset, public deployment or video change.
