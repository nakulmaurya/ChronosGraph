## Scope delivered

### A — True replacement Python diff sandbox

- Added `/api/v1/diff/impact` and MCP `simulate_diff_impact` without changing
  legacy additive `/track1/sandbox-audit` behavior.
- Accept complete multi-file textual Git diffs or explicit final-source maps.
  Add/delete/pure-rename and rename-with-hunks are validated against captured
  source. Null map values delete files. No patch is applied to the working tree.
- GRAPH.COPY rebuilds imports and conservative static calls, replacing changed
  definitions and re-resolving inbound callers. Before/after dependency deltas
  use the same parser/resolver on captured source, not mismatched index versions.
- Preserve pre/post blast-radius union and candidate callers for removed,
  renamed, signature-changed or async-changed functions. Deleted tests remain
  evidence but are not suggested as runnable pytest arguments.
- Exact capture hashes, bounded sizes and strict paths; reject traversal, binary,
  quoted Git paths, symlink modes, missing baselines and malformed final Python.
- Existing AST parse failures are explicitly listed in `parse_coverage` and
  surfaced in the UI. Missing static edges do not mean no impact.
- Verify sandbox cleanup after exit. The indexed base graph is unchanged.

### B — Compact context, source-bound reported memory and actual MCP activity

- `/context/locate`: path/symbol lexical matching plus native File PageRank,
  bounded entry points, signatures, importer/caller/callee evidence, scoped
  current rules, separately labeled source constraints and finding references.
  Actual compact JSON response fits the requested 2–8 KiB byte budget.
- `/context/symbol-source`: exact captured symbol coordinates, source hash and
  bounded UTF-8 source excerpt; ambiguous names fail closed.
- POST/GET `/memory/findings`: save supplied evidence against exact indexed file
  hashes and applicable policy/constraint digest; recall filters stale evidence
  by default. Verification commands are stored as text, never executed.
- Findings explicitly mean **agent-reported evidence**, not an independently
  verified test result. Every new context/source/finding response states
  `PINNED_SNAPSHOT_WORKSPACE_NOT_CHECKED`.
- `/activity`: actual invocations of all ten exposed MCP tools recorded through
  FalkorDB, visible across separate stdio/API processes. No raw code, questions,
  diffs, finding text, commands or exception messages enter activity metadata.
  Latest-500 retention, composite pagination, explicit logging-failure warnings.
- Five core MCP names/interfaces retained; five new tools registered. The
  existing exact tool-set assertions were intentionally expanded, not removed.
