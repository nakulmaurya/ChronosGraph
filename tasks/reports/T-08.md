## Measurement and safety boundaries
Captured decoded-source UTF-8 sizes and Unicode chars//4 equivalents are distinct
from tokenizer output, billed usage and the entire HTTP envelope. The new HUD
compares connected candidate files with the exact Markdown note, not all repository
text. It is a lossy excerpt; reductions can be negative or unavailable. No fixed
95%/90% claim is imposed. `model_calls: 0` and existing zero-model sentinels remain.
Static test candidates are not safe-skip proof. Git author evidence is not verified
maintainer authority. Demo local policies and extracted source constraints retain
separate provenance. Historical rules are flagged, not all proven contradictions.
Recovery rechecks current policy/fingerprint; it is manual, not zero-amnesia magic.

Trusted local single-writer managed export is not distributed crash-safe storage.
The application remains loopback/trusted-user scoped, not a production authorization
or independent security audit. Large graph payloads remain bounded by compiler caps.
Source evidence cannot override the human or host-agent instructions.
