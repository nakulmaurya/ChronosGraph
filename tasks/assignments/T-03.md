## Build
Next.js + TypeScript + Tailwind, @xyflow/react and lucide-react. Dark slate-950
single-screen engineering console with responsive stacked layout on mobile.

1. Header: live tenant catalog (repository names and actual node counts), three
   track tabs, measured Cypher latency badge, accessible copyable MCP config modal
   showing all five tools and local backend command/cwd setup.
2. Left controls: Track 1 real PR catalog + multi-file preset selector + sandbox
   button; Track 2 scenario text + cold/replay buttons; Track 3 question/file
   selector + policy override (scope, rule, rationale) with explicit mutation action.
3. Controlled baseline card: display actual blind_agent_comparison provenance,
   metrics and disclaimers. Never invent generic model failures or token savings.
4. Center: interactive React Flow graph, real edges, labeled statuses ACTIVE,
   SUPERSEDED (dashed/struck), IMPACTED, DEAD_END (PRUNED BY SHORTESTPATH), GOLDEN_PATH;
   animated highlighted cyan edges, zoom/pan/fit controls, node selection inspector.
   Bounded-payload caveat. Exact Cypher and execution time in collapsible drawer.
5. Right: track-specific results, clone cleanup/impacted files/functions/rules,
   evidence-based reviewers (explicit empty snapshot note), current vs superseded
   policies with valid/transaction times, step and measured latency comparison.
6. Topology: 6 cold states / 5 actions / 2 dead ends -> 3 replay actions / 0 dead
   ends / 40% step reduction. Model tokens zero; token_savings_pct zero sentinel.
   Preserve all provenance labels. No 75% token claim, 4x claim, or fake counters.
7. Loading, network/error, empty and stale-playbook states; tenant switching resets
   incompatible results and replay availability. No frontend hardcoded API fixtures.
