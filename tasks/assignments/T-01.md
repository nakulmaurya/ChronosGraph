## Acceptance criteria (individually testable)
1. **AST Parser (`ast_parser.py`):** Given any Python source string or file path, `parse_python_source(source_code: str, file_path: str)` uses stdlib `ast` to return extracted classes, functions (`name`, `qualified_name`, `signature`, `is_async`), imports, and function call names without crashing.
2. **Dual Tenant Seeding (`seed_repos.py`):** Given a running FalkorDB container on `localhost:6379`, when `seed_all_repos()` runs, it populates:
   - `repo_falkordb_py` (`FalkorDB/falkordb-py`): real files (`falkordb/graph.py`, `falkordb/falkordb.py`, `falkordb/node.py`, `falkordb/edge.py`, `falkordb/query_result.py`, `falkordb/asyncio/graph.py`, `falkordb/asyncio/falkordb.py`, `falkordb/cluster.py`, `tests/test_graph.py`, `tests/test_async.py`), real functions (`Graph.query`, `Graph.ro_query`, `Graph.copy`, `Graph.delete`, `FalkorDB.select_graph`, `AsyncGraph.query`, `AsyncGraph.ro_query`, `QueryResult._parse_results`, etc.), `[:IMPORTS]` and `[:CALLS]` edges, real contributors (`gkorland`, `roi-lipman`, `swilly22`, `avi-avni`), real PRs (`#42`, `#58`, `#64`, `#71`, `#83`), open issues (`#89`, `#92`), and at least 4 bi-temporal `(:Decision {status: 'ACTIVE'})-[:SUPERSEDED]->(:Decision {status: 'SUPERSEDED'})` chains with `vecf32($embedding)` vectors.
   - `repo_graphrag_sdk` (`FalkorDB/GraphRAG-SDK`): real files (`graphrag_sdk/kg.py`, `graphrag_sdk/ontology.py`, `graphrag_sdk/orchestrator.py`, `graphrag_sdk/agents/kg_agent.py`, `graphrag_sdk/steps/graph_query_step.py`, `graphrag_sdk/models/litellm.py`, `tests/test_kg.py`), functions, contributors, PRs, open issues, and at least 3 bi-temporal `[:SUPERSEDED]` decision chains.
3. **PageRank Calculation:** Calls `CALL algo.pageRank('File', 'IMPORTS') YIELD node, score` (with safe degree-based fallback) and sets `f.pagerank` on every `(:File)` node.
