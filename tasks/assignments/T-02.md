## Acceptance criteria (individually testable)
1. **Track 1 (`sandbox_auditor.py`):** Uses `with db_manager.ephemeral_sandbox(req.tenant_graph) as (sandbox_graph, sandbox_name, clone_ms):`, applies simulated AST edges, executes `CYPHER_BLAST_RADIUS_AUDIT` and `CYPHER_FILE_OWNERSHIP_AND_LINEAGE`, populates `BlindAgentComparison` (controlled one-hop/oldest-document comparison, not an LLM benchmark), and verifies `sandbox_cleaned_up == True`.
2. **Track 3 (`company_brain.py`):**
   - `ask_brain`: Uses `db_manager.ro_query` with `CYPHER_HYBRID_VECTOR_DECISION_SEARCH` and `CYPHER_FILE_OWNERSHIP_AND_LINEAGE`. Returns `PolicyLineageResponse` with `VisualNode` statuses (`ACTIVE` vs `SUPERSEDED`).
   - `override_policy`: Executes `CYPHER_SUPERSEDE_DECISION` to flip the previous `ACTIVE` decision on `target_file_path` to `SUPERSEDED` and link the new `ACTIVE` decision via `[:SUPERSEDED]`.
3. **Track 2 (`memory_compiler.py`):**
   - `cold_multi_agent` mode: Creates `(:Investigation)` and a 6-node `(:StateNode)` branching graph (`START` -> 2 `DEAD_END` branches explored by `Scout` via `ro_query` + 1 valid path through `Historian` via `ro_query` and `Verifier` to `VERIFIED_GOAL`). Runs `CYPHER_COMPILE_PLAYBOOK_SHORTEST_PATH` (`shortestPath`) to prune dead ends and saves a `(:ProceduralPlaybook)` linked to `(:AnomalySignature)`.
   - `compiled_playbook` mode: Matches `(:AnomalySignature)` via vector index and executes three retained tool actions (vs five cold actions), with zero dead ends (vs two cold), 40% fewer tool executions, tokens_used=0 and token_savings_pct=0.0 sentinels, and measured local replay speedup >1.0.
4. **FastAPI (`main.py`) & FastMCP (`mcp_server/server.py`):** Exposes `/api/v1/tenants`, `/api/v1/subgraph`, `/api/v1/track1/sandbox-audit`, `/api/v1/track3/ask-brain`, `/api/v1/track3/override-policy`, `/api/v1/track2/investigate`, and the 5 MCP tools. Auto-seeds on startup if graphs are missing.
5. **E2E Tests (`tests/test_e2e_graph.py`):** Tests all endpoints and asserts all invariants against live FalkorDB.
