# Product Brief — ChronosGraph

Version v1.2 | Approved deterministic zero-key scientific scope (CR-002)

## Problem and audience
Maintainers and coding-tool developers need connected context: what imports/calls a
file, which rule is current, what rule it superseded, and which successful tool
sequence can be replayed. This prototype investigates that workflow on two pinned
FalkorDB open-source snapshots. No generic competitor failure claim is established.

## Observable MVP
1. GRAPH.COPY creates a disposable graph for explicitly labeled proposed dependency
   scenarios. Canonical multi-hop queries expose static impact; cleanup is verified.
2. Current and superseded demo policies are attached to real files/contextual PRs.
   They are fictional DEMO_POLICY_SCENARIO rules, not upstream policy history. Local
   overrides preserve lineage; limited PR-linked reviewer evidence is transparent.
3. Deterministic Scout/Historian/Verifier tools log six states/five actions with two
   alternate-file dead ends. Native shortestPath retains three actions; replay
   eliminates dead-end work and reduces tool executions by 40%, with measured timing.
4. FastAPI and five FastMCP tools expose the graph to a Next.js flight recorder.

## Evidence and limitations
Real native FalkorDB execution, real AST/public GitHub provenance, zero sandbox
leaks, current-policy retrieval and stale-playbook invalidation are tested. Models
are not called: zero-token fields are sentinels, not token/cost savings. Hash
vectors are lexical, not learned semantic embeddings. A static scenario cannot
prove a runtime outage or automatically fix a bug. Source/visual coverage is bounded.

## Constraints
Zero mandatory API spend; no paid model connection. Single trusted local user,
localhost services, no authentication/production deployment. Approved local clone
ceiling <250 ms; actual measured replay speedup >1.0 in acceptance, not a universal
performance promise. No claim about current hackathon prizes, deadlines or judging
was reverified as part of this implementation task.
